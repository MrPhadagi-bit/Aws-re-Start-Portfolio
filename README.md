# Aws-re-Start-Portfolio

AWS re/Start portfolio website for documenting cloud projects, technical skills, and learning progress.

## Files

- `index.html` - Portfolio page structure
- `styles.css` - Responsive visual styling

## Customize

Update the placeholder email in `index.html`:

```html
mailto:your.email@example.com
```

Then replace the sample project cards with your completed AWS labs and portfolio work.
