# AWS re/Start Portfolio

This repository documents my AWS re/Start learning journey, including cloud foundations, Linux, Python, networking, security, databases, infrastructure management, and operations.

## Core Tech Stack

The program focuses on five primary technical pillars:

| Pillar | Focus Area |
| --- | --- |
| AWS Core Services | Foundational AWS infrastructure including Amazon EC2 for compute, Amazon S3 for storage, Amazon RDS for relational databases, and Amazon VPC for networking. |
| Operating Systems | Linux command line, file system navigation, user management, permissions, and bash shell scripting. |
| Programming | Python fundamentals including syntax, data types, control flow, loops, conditionals, functions, and task automation. |
| Networking | TCP/IP fundamentals, IP subnetting, routing, DNS, and Route 53 concepts. |
| Security | Cloud security principles, Identity and Access Management, and securing AWS resources. |

## Key Concepts and Modules

| Category | Key Concepts Covered |
| --- | --- |
| Cloud Foundations | Cloud economics, AWS global infrastructure, Regions, Availability Zones, and the shared responsibility model. |
| Databases | Relational database concepts, SQL basics, and managing database instances with Amazon RDS. |
| Infrastructure Management | Virtual Private Cloud design, Elastic Load Balancing, and Auto Scaling. |
| Operations and Monitoring | Troubleshooting, technical support basics, and monitoring AWS resources with Amazon CloudWatch. |
| Emerging Technology | Introductory concepts for containers, serverless computing, and automation. |

## Learning Goals

- Build a strong foundation in AWS cloud services.
- Practice Linux, networking, security, and Python fundamentals.
- Understand how cloud infrastructure is designed, deployed, secured, and monitored.
- Document hands-on labs and projects that show practical cloud skills.

## Repository Purpose

This portfolio will be used to track progress, organize project work, and demonstrate technical growth throughout the AWS re/Start program.
