The first project is based on a restaurant-style website called **Zani Eatery**. It demonstrates how static website files can be organized, uploaded, and hosted using Amazon S3.

## Recommended Project Documentation Format

Use this structure when adding new projects:

1. **Overview** - Explain the purpose of the project and the problem it solves.
2. **Tools and Services** - List AWS services, programming languages, and supporting tools.
3. **Architecture or Workflow** - Describe how the solution works from start to finish.
4. **Steps Completed** - Document the main build or deployment steps.
5. **Challenges and Solutions** - Record issues encountered and how they were resolved.
6. **What I Learned** - Summarize the technical and professional skills gained.
7. **Future Improvements** - Add realistic next steps for making the project stronger.
