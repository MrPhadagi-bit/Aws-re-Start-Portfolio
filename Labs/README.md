# Labs

This folder contains hands-on labs and practice exercises completed during the AWS re/Start programme. The labs are organized by topic to make it easy to review cloud fundamentals, revisit commands, and demonstrate practical skills.

## Lab Areas

| Area | Focus |
|---|---|
| `Compute/` | EC2, AWS Lambda, serverless workflows, AWS CLI, and compute troubleshooting labs. |
| `Networking/` | VPC, subnetting, routing, DNS, and network security labs. |
| `Linux/` | Linux command line, permissions, users, processes, and shell scripting exercises. |
| `Python/` | Python programming fundamentals and automation exercises. |
| `Databases/` | SQL, relational database concepts, Amazon RDS, and database connectivity labs. |
| `Security/` | IAM, access control, shared responsibility, encryption, monitoring, and AWS security best practices. |

## How To Use This Folder

1. Open a topic folder that matches the skill you want to review.
2. Read the lab notes or walkthrough for the scenario, service, and commands used.
3. Use screenshots, summaries, and command examples as evidence of hands-on practice.
4. Return to this README as the index for future lab additions.

## Skills Demonstrated

- Deploying and troubleshooting AWS compute resources
- Applying core Linux and shell command knowledge
- Understanding network design and cloud connectivity
- Practicing identity, access, encryption, and security controls
- Working with relational databases and SQL concepts
- Writing basic Python scripts for programming fundamentals and automation
