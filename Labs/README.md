# Labs

This folder contains hands-on labs and practice exercises completed during the AWS re/Start programme. The labs are organized by topic so cloud fundamentals, command examples, service notes, and troubleshooting steps are easy to find and review.

## Lab Index

| Area | Labs | Focus |
|---|---:|---|
| [Compute](./Compute/) | 8 | Amazon EC2, AWS Lambda, AWS CLI setup, instance troubleshooting, and compute fundamentals. |
| [Networking](./Networking/) | 8 | Amazon VPC, subnets, IP addressing, public and private networks, protocols, and troubleshooting commands. |
| [Linux](./Linux/) | 16 | Linux CLI, files, permissions, users, groups, processes, services, logs, package management, and bash scripting. |
| [Python](./Python/) | 3 | Python basics, Hello World, strings, numeric data types, and beginner programming practice. |
| [Databases](./Databases/) | 4 | SQL basics, table operations, selecting data, and insert, update, and delete statements. |
| [Security](./Security/) | 7 | IAM, encryption, monitoring, vulnerability assessment, patching, malware protection, and AWS security services. |

## Recommended Review Path

1. Start with [Linux](./Linux/) to strengthen command-line and system administration fundamentals.
2. Move to [Networking](./Networking/) to understand IP addressing, VPC design, subnetting, and connectivity.
3. Review [Compute](./Compute/) for EC2, Lambda, AWS CLI, and troubleshooting practice.
4. Study [Security](./Security/) to connect IAM, encryption, monitoring, patching, and vulnerability management.
5. Complete [Databases](./Databases/) for SQL and relational database fundamentals.
6. Use [Python](./Python/) to reinforce scripting and programming basics.

## What Each Lab Documents

Most lab notes include:

- The service, tool, or concept being practiced
- The main objective of the lab
- Important commands, configuration steps, or screenshots
- Troubleshooting notes and lessons learned
- Evidence of hands-on practice for portfolio review

## Skills Demonstrated

- Deploying, configuring, and troubleshooting AWS compute resources
- Building foundational networking knowledge for cloud environments
- Using Linux commands for administration, files, services, logs, and permissions
- Applying AWS security concepts such as IAM, encryption, monitoring, and patch management
- Practicing SQL queries and relational database operations
- Writing beginner Python programs and understanding core data types
- Documenting technical work clearly for interviews and portfolio presentation

## Portfolio Purpose

These labs show steady progress through the AWS re/Start curriculum and create a practical record of cloud learning. They can be used to revise key concepts, explain hands-on experience during interviews, and demonstrate readiness for entry-level cloud, infrastructure, or technical support roles.
