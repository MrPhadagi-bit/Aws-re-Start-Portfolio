# Database Labs

This folder contains database-focused labs from my AWS re/Start learning journey. The work in this section is focused on understanding how databases support cloud applications, how managed database services are configured in AWS, and how database environments are secured, monitored, and backed up.

## Learning Objectives

- Understand relational database concepts such as tables, rows, columns, keys, and relationships
- Practise basic SQL commands for reading and managing data
- Learn how Amazon RDS simplifies database provisioning and maintenance
- Understand how networking and security controls affect database access
- Explore database backup, restore, monitoring, and high availability concepts

## Core Topics

| Topic | Focus Area |
|---|---|
| Relational databases | Database structure, relationships, and data organization |
| SQL fundamentals | SELECT, INSERT, UPDATE, DELETE, filtering, and sorting |
| Amazon RDS | Creating and managing a cloud-hosted relational database |
| Database connectivity | Connecting to a database endpoint from a client or application |
| Network security | Security groups, VPC access, and controlled connectivity |
| Access management | Database users, credentials, and basic permission practices |
| Backups and recovery | Snapshots, restore options, and recovery planning |
| Monitoring | CloudWatch metrics, database health, and troubleshooting signals |
| High availability | Multi-AZ concepts and reliability planning |

## AWS Services Used
