# Database Labs

## About This Folder

This folder is for my AWS re/Start database labs and notes. It focuses on relational database concepts, SQL basics, Amazon RDS, database connectivity, backups, monitoring, and high availability.

At the moment, this section is prepared as a placeholder for upcoming database lab documentation. As I complete more labs, I will add the lab files here and update this README with direct links.

## Topics Covered

| Area | Focus |
|---|---|
| Database Fundamentals | Tables, records, columns, keys, and relationships |
| SQL Basics | Querying, filtering, sorting, inserting, updating, and deleting data |
| Amazon RDS | Managed relational databases in AWS |
| Connectivity | Connecting applications or clients to a database endpoint |
| Security | Database users, passwords, access control, and network rules |
| Backups | Snapshots, restore points, and recovery planning |
| Availability | Multi-AZ concepts and reliability planning |
| Monitoring | Basic database performance and health checks |
