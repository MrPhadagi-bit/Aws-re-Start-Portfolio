# Database Labs

This section documents my AWS re/Start database learning, with a focus on relational database fundamentals, SQL, Amazon RDS, database security, backups, monitoring, and high availability.

## Purpose

The goal of these labs is to show practical understanding of how cloud databases are created, secured, connected, maintained, and monitored in AWS. These skills are useful for cloud support, solutions architecture, DevOps, and application operations roles.

## Topics Covered

| Area | What I Practised |
|---|---|
| Database fundamentals | Tables, rows, columns, primary keys, foreign keys, and relationships |
| SQL basics | Selecting, filtering, sorting, inserting, updating, and deleting records |
| Amazon RDS | Creating and managing a relational database service in AWS |
| Connectivity | Connecting to a database endpoint from a client or application |
| Security | Managing users, passwords, security groups, and access control |
| Backups and recovery | Creating snapshots and understanding restore options |
| Monitoring | Reviewing database health, metrics, and performance indicators |
| High availability | Understanding Multi-AZ deployments and reliability planning |

## AWS Services and Tools

- Amazon RDS

- Amazon VPC
