# Security Labs

This folder contains AWS security labs and notes from the AWS re/Start programme. The labs focus on identity and access management, data protection, monitoring, vulnerability assessment, patching, malware protection, and security logging.

## Lab Index

| Lab | Focus |
|---|---|
| [Introduction to AWS IAM](./Introduction_to_AWS_IAM_Lab.md) | Users, groups, roles, policies, and secure access management. |
| [Data Protection Using Encryption](./Data_Protection_Using_Encryption.md) | Protecting data with encryption and key security concepts. |
| [Monitoring Infrastructure](./Monitoring_Infrastructure_Lab_Overview.md) | Observing AWS resources and understanding infrastructure monitoring. |
| [Monitor EC2 Instance](./Monitor_EC2_Instance_Lab.md) | Tracking EC2 instance health, metrics, and operational signals. |
| [Working with AWS CloudTrail](./Working_with_AWS_CloudTrail_Activity_Overview.md) | Auditing account activity and reviewing API event history. |
| [Amazon Inspector Vulnerability Assessment and Remediation](./Using_Amazon_Inspector_for_Vulnerability_Assessment_and_Remediation.md) | Finding vulnerabilities and planning remediation steps. |
| [Systems Hardening with Patch Manager](./Systems_Hardening_with_Patch_Manager_via_AWS_Systems_Manager.md) | Applying patches and strengthening systems with AWS Systems Manager. |
| [Malware Protection with AWS Network Firewall](./Malware_Protection_AWS_Network_Firewall.md) | Understanding network-level protection and malware defense concepts. |

## Skills Practiced

- Applying the AWS Shared Responsibility Model to security decisions
- Managing IAM users, groups, roles, and permissions
- Using encryption to protect data at rest and in transit
- Monitoring infrastructure activity and EC2 instance behavior
- Reviewing CloudTrail logs for visibility and accountability
- Identifying vulnerabilities with Amazon Inspector
- Improving system security through patch management and hardening
- Understanding malware protection and network firewall controls

## Portfolio Value

These labs demonstrate practical security awareness for cloud support and entry-level cloud engineering roles. They show experience with foundational AWS security services, operational monitoring, vulnerability management, and clear documentation of hands-on practice.
