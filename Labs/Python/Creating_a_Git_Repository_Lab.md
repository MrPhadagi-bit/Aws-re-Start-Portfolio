# Creating a Git Repository - Lab Overview

## Introduction

GitHub runs an instance of **Git**, which is version-control software that runs in the cloud. GitHub is popular among open source projects and businesses.

In this lab, you will:

- Download solutions for the earlier labs
- Create a GitHub account
- Read the GitHub Hello World guide
- Create a private repository for your labs
- Download your repository

## Estimated Completion Time

**45 minutes**

---

## Exercise 1: Downloading Your Python Files from Previous Labs

To download the project files:

1. In your IDE, **right-click** the folder in the **Explorer** panel and choose **Download**.

   > **Note:** This action creates an untitled file and downloads a compressed (`.zip`) file onto your local machine.

2. **Extract** the contents of the downloaded `.zip` file.

---

## Exercise 2: Creating a GitHub Account

At the time of this writing, GitHub offered a free account for individuals.

1. Visit GitHub at [https://www.github.com](https://www.github.com) and create an account.

---

## Exercise 3: Reading the GitHub Hello World Guide

After you log in to GitHub, you can access the Hello World guide for creating a repository.

1. Read the GitHub Hello World guide at [https://guides.github.com/activities/hello-world/](https://guides.github.com/activities/hello-world/)

   > **Tip:** This guide walks you through the basics of creating a repository, branching, making commits, and opening pull requests.

---

## Exercise 4: Creating a Private Repository

After you read the GitHub Hello World guide, make sure that you are logged in to GitHub and follow these steps:

### Step 1: Start Creating a New Repository

1. Click the **New** button (or the **+** icon in the top-right corner and select **New repository**).
2. The **Create a new repository** form will open.

### Step 2: Configure Your Repository

1. Give your repository a name, such as `aws_restart`.
2. **Visibility:** Choose **Private** (you can also choose Public, but for this lab, select Private).
3. **Initialize this repository with a README:** ✅ Check this option.

   > **Why a README?** A README file helps others understand what your project is about and how to use it.

### Step 3: Create the Repository

1. Click **Create repository**.

If your repository is created successfully, you should see a default repository with a `README.md` file.

### Step 4: Upload Your Lab Files

1. Click the **Upload files** button on your repository page.
2. Upload all the files that you previously extracted in **Exercise 1**.
3. Add a commit message (e.g., `Add lab solution files`) and click **Commit changes**.

---

## Exercise 5: Downloading a Repository

To download your repository to your local machine:

### Step 1: Download as ZIP

1. On your repository page, click the **Code** button (previously labeled **Clone or download**).
2. Select **Download ZIP**.

### Step 2: Save and Extract

1. On your local machine, create a folder named `aws_restart`.
2. Save the downloaded `.zip` file into this folder.
3. Extract the `.zip` file to verify that all files were downloaded correctly.
