# Python Labs

This folder contains Python practice labs completed as part of my AWS re/Start learning journey. These exercises focus on building the programming fundamentals needed for cloud support, automation, scripting, and DevOps workflows.

## Learning Objectives

- Build confidence writing and running Python scripts
- Understand variables, data types, operators, and program structure
- Use conditional logic and loops to solve problems
- Write functions to organize reusable code
- Practise reading from and writing to files
- Develop debugging and problem-solving habits
- Connect programming concepts to cloud and automation tasks

## Core Topics

| Topic | Focus Area |
|---|---|
| Python syntax | Writing clear and structured Python scripts |
| Variables and data types | Working with strings, numbers, booleans, lists, and dictionaries |
| Operators | Using arithmetic, comparison, and logical operators |
| Conditional logic | Making decisions with `if`, `elif`, and `else` statements |
| Loops | Repeating tasks with `for` and `while` loops |
| Functions | Organizing code into reusable blocks |
| File handling | Reading, writing, and updating files |
| Error handling | Understanding errors and improving scripts through debugging |
| Automation basics | Using Python to simplify repeated technical tasks |

## How to Run the Labs

1. Open a Python lab file in this folder.
2. Review the comments, prompts, or instructions in the script.
3. Run the file from a terminal:

```bash
python filename.py
```

4. Review the output, test different inputs, and update the code where needed.
