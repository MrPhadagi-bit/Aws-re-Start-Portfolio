# Python Labs

This folder contains Python practice labs completed as part of the AWS re/Start portfolio. The exercises build core programming skills through small, focused scripts and problem-solving tasks.

## Topics Covered

- Python syntax and script structure
- Variables and data types
- Conditional logic
- Loops and iteration
- Functions
- File handling
- Basic automation concepts
- Debugging and problem solving

## How to Use These Labs

1. Open a lab file in this folder.
2. Read the comments or prompts in the script.
3. Run the program with Python:

```bash
python filename.py
```

4. Review the output and update the code as needed.

## Skills Demonstrated

These labs demonstrate foundational Python skills used in cloud, automation, and DevOps workflows, including writing readable code, working with input and output, using control flow, and breaking problems into smaller steps.
